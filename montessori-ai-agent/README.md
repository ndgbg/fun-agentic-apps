# 🌱 Montessori AI Agent

An autonomous AI assistant for Montessori-based early childhood development. Uses real LLM reasoning to provide personalized activity recommendations that adapt to your child's unique learning patterns.

## ✨ Features

- **🤖 Autonomous AI** - Real LLM integration (OpenAI, Anthropic, Ollama) with continuous learning
- **🎯 Personalized Activities** - Age-appropriate Montessori activities tailored to your child
- **📊 Smart Adaptation** - Learns from engagement patterns and adjusts recommendations
- **🔒 Privacy-First** - All data stored locally, no external accounts required
- **📱 Mobile-Optimized** - Beautiful, responsive interface for parents

## 🚀 Quick Start

```bash
git clone https://github.com/yourusername/fun-agentic-apps.git
cd fun-agentic-apps/montessori-ai-agent
npm install
npm run dev
```

### AI Setup (Optional)
1. Go to Profile → 🧠 AI Configuration
2. Add your API key from [OpenAI](https://platform.openai.com/api-keys) or [Anthropic](https://console.anthropic.com/)
3. The AI will start providing personalized recommendations

## 🧠 How It Works

The AI continuously observes your child's engagement, reasons about their developmental needs using Montessori principles, and autonomously generates personalized activities.

```
OBSERVE → REASON → ACT → LEARN
   ↑                      ↓
   ←──────────────────────
```

**Example**: Child shows high engagement with fine motor activities → AI reasons they're ready for advanced challenges → Generates custom threading activity → Learns from the outcome

## 🛠️ Tech Stack

- **Frontend**: React 18, Styled Components, Vite
- **AI**: OpenAI GPT-4, Anthropic Claude, Ollama
- **Storage**: Local Storage (privacy-first)
